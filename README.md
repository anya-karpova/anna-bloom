# ANNA BLOOM — интернет-магазин цветочных инсталляций

Готовый адаптивный сайт на **HTML + CSS + JavaScript**, без сборки и платных сервисов. Предназначен для публикации на **GitHub Pages**.

## Что работает

- Каталог инсталляций с 10 демо-товарами; карточки, подробное описание, фильтры, поиск и сортировка.
- Избранное и корзина с количеством товаров (сохраняются локально на устройстве покупателя).
- Форма заказа: имя, телефон, дата, место и пожелания, согласие с условиями.
- После заполнения формы **создаётся текст заявки и ссылка в WhatsApp** на номер `+7 951 883-62-81`. **Покупатель должен самостоятельно нажать «Отправить» в WhatsApp**. Сайт не отправляет сообщения автоматически и не записывает заявки в онлайн-базу.
- Кнопки звонка, Telegram `@Anya_karpova` и WhatsApp.
- Адаптивная мобильная версия, FAQ, навигация, полоса быстрого контакта.
- Все SVG-иллюстрации поставляются вместе с проектом. Ничего не надо скачивать для изображений (шрифты Geologica / Playfair Display загружаются из Google Fonts, есть резервные системные).

## Как разместить на GitHub Pages

1. Зайдите на GitHub → **New repository**. Например, `anna-bloom`.
2. Загрузите **содержимое папки** в корень репозитория: `index.html`, `styles.css`, `catalog.js`, `app.js` и **папку `assets/`**. Можно использовать **Add file → Upload files** или загрузить файлы через Git.
3. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.
4. После публикации адрес обычно вида `https://ИМЯ_АККАУНТА.github.io/anna-bloom/`. Точный адрес будет показан в Settings → Pages.

> Можно открыть `index.html` локально в браузере; для разработки также подходит Live Server в VS Code.

## Где менять товары

Все товары находятся в `catalog.js` в массиве `window.BLOOM_PRODUCTS`. Для каждого товара:

```js
{
  id: 'unique-id',
  name: 'Название',
  category: 'Ростовые цветы',
  price: 12900,
  picture: 'assets/my-real-photo.webp',
  tint: 'rose',
  badge: 'по заказу',
  info: 'Описание',
  details: ['Размер согласовывается', 'Выбор палитры']
}
```

Цена **пока демонстрационная**: установите реальные цены и замените изображения на свои фотографии до начала продаж. `price` — целое число в рублях. Допустимые категории: `Ростовые цветы`, `Фотозоны`, `Арки`, `Композиции`, `Оформление`. Не удаляйте `assets/`, пока товары используют SVG-файлы из неё.

## Где менять контакты и бренд

- Номер телефона, ссылки WhatsApp и Telegram: текст в `index.html`; в `app.js` константа `PHONE`.
- Название бренда «ANNA BLOOM»: заголовок, логотип, метаописание и футер в `index.html`.
- Основная цветовая палитра: начало `styles.css` → `:root`. Пастельный розовый фон + сливочные и лиловые оттенки, салатовый футер.

## Важное про заявки и оплату

**GitHub Pages — статический хостинг:** он не принимает заявки на сервер и не отправляет СМС или сообщения от имени посетителя. В данной версии заявка готовится на сайте и вручную отправляется покупателем через WhatsApp. Чтобы заявки поступали даже без открытия мессенджера, нужно подключить сервер, Google Apps Script / форму с backend, CRM или другой сервис — и протестировать доставку данных.

**Оплата не подключена.** Кнопки «оплатить» и фиктивные логотипы эквайринга специально отсутствуют. Подключать оплату можно после выбора платёжного провайдера и оформления необходимых реквизитов.

**Юридические данные:** перед использованием в коммерции оформите реальную политику обработки персональных данных, сведения о продавце/исполнителе, условия оформления заказов, доставки и возврата (если применимо), и убедитесь в соблюдении действующих требований о персональных данных. В текущем файле `index.html` содержится прозрачное описание поведения демо-формы, но это **не готовая юридически выверенная политика**. Не размещайте в публичном доступе ключи/токены для Telegram-бота и других интеграций.

## Исходники графики

Файлы `assets/*.svg` — самостоятельные декоративные иллюстрации, созданные для макета. Они **не являются фотографиями готовых работ**. За настоящие работы их выдавать нельзя.
