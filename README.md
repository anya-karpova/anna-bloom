# ANNA BLOOM — интернет-магазин цветочных инсталляций

Готовый адаптивный сайт на **HTML + CSS + JavaScript**, без сборки и платных сервисов. Предназначен для публикации на **GitHub Pages**.

## Что работает

- Каталог инсталляций с 10 демо-товарами; карточки, подробное описание, фильтры, поиск и сортировка.
- Избранное и корзина с количеством товаров (сохраняются локально на устройстве покупателя).
- Форма заказа: имя, телефон, дата, место и пожелания, согласие с условиями.
- После заполнения формы **создаётся текст заявки и ссылка в WhatsApp** на номер `+7 951 883-62-81`. **Покупатель должен самостоятельно нажать «Отправить» в WhatsApp**. Сайт не отправляет сообщения автоматически и не записывает заявки в онлайн-базу.
- Кнопки звонка, Telegram `@Anya_karpova` и WhatsApp.
- Адаптивная мобильная версия, FAQ, навигация, полоса быстрого контакта.
- Все SVG-иллюстрации поставляются вместе с проектом. Ничего не надо скачивать для изображений (шрифты Geologica / Playfair Display загружаются из Google Fonts, есть резервные системные).


## Структура

```
index.html        — разделы и разметка сайта
styles.css        — дизайн + мобильная адаптация
catalog.js        — товары, названия, изображения, цены
app.js            — каталог, корзина, формы, WhatsApp
assets/*.svg      — изображения цветов и оформления
README.md         — эта инструкция
```
