# ANNA BLOOM — интернет-магазин цветочных инсталляций

Готовый адаптивный сайт на **HTML + CSS + JavaScript**, без сборки и платных сервисов. Предназначен для публикации на **GitHub Pages**.

## Что работает

- Каталог инсталляций с 10 демо-товарами; карточки, подробное описание, фильтры, поиск и сортировка.
- Избранное и корзина с количеством товаров (сохраняются локально на устройстве покупателя).
- Форма заказа: имя, телефон, дата, место и пожелания, согласие с условиями.
- После заполнения формы **создаётся текст заявки и ссылка в WhatsApp** на номер `+7 951 883-62-81`. **Покупатель должен самостоятельно нажать «Отправить» в WhatsApp**. Сайт не отправляет сообщения автоматически и не записывает заявки в онлайн-базу.
- Кнопки звонка, Telegram `@Anya_karpova` и WhatsApp.
- Адаптивная мобильная версия, FAQ, навигация, полоса быстрого контакта.
- Все SVG-иллюстрации поставляются вместе с проектом. Ничего не надо скачивать для изображений (шрифты Geologica / Playfair Display загружаются из Google Fonts, есть резервные системные).


## Структура

```
index.html        — разделы и разметка сайта
styles.css        — дизайн + мобильная адаптация
catalog.js        — товары, названия, изображения, цены
app.js            — каталог, корзина, формы, WhatsApp
assets/*.svg      — изображения цветов и оформления
README.md         — эта инструкция
```


## Автоматические заявки в Google Sheets (не активировано до развертывания)

Создана отдельная таблица: https://docs.google.com/spreadsheets/d/1AN5KH3bsl-ckGF8k8xkLqL1kmKiHb3CUS38Ar94jSuk/edit

В GitHub включены: конфигурация `config.js`, серверный скрипт `Code.gs`, проверка записи по номеру заявки и резервная отправка в WhatsApp. Чтобы **включить автоматическую запись**, нужно один раз опубликовать `Code.gs` как Apps Script Web App и добавить выданный URL в `config.js`. Инструкция: [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md).

Пока `BLOOM_SHEETS_ENDPOINT` пуст, сайт продолжает отправлять заявки **только вручную через WhatsApp**. Подтверждённых тестов передачи реальных данных не проводилось.

**Для бизнеса в России:** перед сбором данных реальных клиентов проверьте требования 152-ФЗ о локализации персональных данных. Google Sheets не рекомендуется использовать как первичную базу российских клиентов; для коммерческого запуска нужен соответствующий требованиям РФ сервер и уточнённая политика.


## Редизайн Floral Editorial Atelier (октябрь 2026)

Ветка `design/floral-editorial-redesign` переносит визуальную концепцию ANNA BLOOM:

- тёплый айвори-фон `#FBF8F5`, сливовый `#653A4D`, пудрово-розовый `#F7E8E7`;
- сочетание Cormorant Garamond для крупных заголовков и Manrope для интерфейса;
- крупный первый экран, блок преимуществ, категории, каталог в четыре колонки на десктопе;
- два столбца товаров на смартфонах и фиксированная нижняя навигация магазина;
- новая серия оригинальных SVG-иллюстраций `assets/editorial-hero.svg` и `assets/editorial-flower-1.svg` … `editorial-flower-10.svg`.

**Сохранение функций:** `app.js`, `config.js`, `Code.gs` и схема заказа не заменялись. Каталог сохраняет идентификаторы, названия, категории, цены, описания и характеристики; изменены только пути к демонстрационным изображениям. Корзина, избранное, фильтры, WhatsApp и опциональная интеграция с таблицей остаются действующими по существующей логике.

**Важно:** иллюстрации — концептуальная графика, не фотографии произведённых товаров. Перед реальными продажами замените их проверенными фото, подтвердите цены и условия изготовления и соблюдайте требования к обработке персональных данных. Изменения проверены на уровне структуры HTML, наличия используемых JS-элементов и ассетов; браузерное E2E-тестирование требуется до коммерческого запуска.
