# Подключение заявок ANNA BLOOM к Google Таблице

Таблица: https://docs.google.com/spreadsheets/d/1AN5KH3bsl-ckGF8k8xkLqL1kmKiHb3CUS38Ar94jSuk/edit

**ВАЖНО ДЛЯ РЕАЛЬНОГО БИЗНЕСА В РФ.** Google Sheets/Apps Script не следует использовать как первичное хранилище персональных данных российских покупателей без юридической проверки требований 152-ФЗ, включая локализацию данных в РФ. Для реального запуска рекомендуется российский backend/хранилище. Следующий способ подходит для демонстрации и проверки с тестовыми данными.

## Однократная настройка
1. Откройте таблицу под **рабочим Google-аккаунтом**, на котором создана таблица.
2. **Расширения → Apps Script** (на телефоне может потребоваться режим «Версия для ПК»).
3. Удалите стандартную функцию myFunction. Скопируйте ВЕСЬ код из файла **Code.gs** этого репозитория и вставьте в редактор Google Apps Script. Сохраните.
4. Нажмите **Deploy / Развернуть → New deployment / Новое развертывание → Web app / Веб-приложение**.
5. **Execute as / Выполнять от имени: Me / Меня. Who has access / У кого есть доступ: Anyone / Все.** Разрешите запрошенный Google доступ к таблице. Не меняйте доступ самой таблицы на «Все».
6. Скопируйте предоставленный адрес веб-приложения вида `https://script.google.com/macros/s/.../exec` (важно: в конце `/exec`, не `/dev`).
7. На GitHub откройте **config.js → Edit** и замените пустые кавычки в `window.BLOOM_SHEETS_ENDPOINT = '';` на URL из шага 6. Сохраните commit.
8. После обновления GitHub Pages сделайте тестовую заявку со своими **тестовыми** данными. Дождитесь подтверждения «записано в таблицу» и проверьте строку в таблице на вкладке **Заявки**.

## Как работает
Форма отправляет заявку из сайта через веб-приложение Apps Script. В таблицу добавляется строка со временем, номером, статусом, телефоном, пожеланиями, товарами и ориентировочной стоимостью. Есть антидублирование по номеру заявки, базовая проверка данных и защита от формул в ячейках. На сайте запрашивается отдельное подтверждение сохранения по номеру заявки; оно **не раскрывает персональные данные**.

При недоступном сервисе клиент получает кнопку WhatsApp для ручной отправки заявки. Без URL в config.js сайт работает в старом режиме: текст заявки формируется для WhatsApp, никакая запись в Google Sheets не происходит.

**Внимание:** публичный веб-обработчик может получать спам. Для коммерческого проекта желательно предусмотреть ограничение частоты, CAPTCHA, уведомления и законный способ обработки персональных данных.
